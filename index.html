PENCATATAN PELANGGARAN OSIS & MPS
SMAN 3 GARUT

Bobot Pelanggaran

  • Pelanggaran Ringan: -5 Poin
  • Pelanggaran Berat: -15 Poin
  • Poin Awal Setiap Anggota: 100 Poin

Tingkat Sanksi

Berkurang ≥ 25 Poin (Sisa ≤ 75): SP 1
Berkurang ≥ 50 Poin (Sisa ≤ 50): SP 2
Poin Habis (0 Poin): SP 3

Pelanggaran Harian

KRITERIA PELANGGARAN BERAT (-15 POIN)

  • • Rapat tanpa keterangan apapun
  • • Merokok / Bolos / Kasus seksual
  • • Mencoreng nama baik sekolah / organisasi
  • • Almet dipakai oleh orang lain / Menyalagunakan jabatan
  • • Pacaran berlebihan

KRITERIA PELANGGARAN RINGAN (-5 POIN)

  • • Kesiangan 2x
  • • Make up berlebihan 2x
  • • Atribut tidak lengkap 3x
  • • Tidak melaksanakan tugas 3x
  • • Izin saat ada rapat tanpa keterangan yang jelas 3x

Pelanggaran Event / Kegiatan

KRITERIA PELANGGARAN BERAT (-15 POIN)

  • • Tidak hadir tanpa keterangan 2x berturut-turut / 3x akumulasi
  • • Tidak mengikuti evaluasi / acara tanpa keterangan
  • • Hilang/tidak memberikan kabar saat dibutuhkan organisasi
  • • Bolos / Merokok / Kasus seksual
  • • Mencoreng nama baik / Menyalahgunakan jabatan / Almet dipinjamkan

KRITERIA PELANGGARAN RINGAN (-5 POIN)

  • • Kesiangan 2x
  • • Menggunakan/membawa make up berlebihan 3x
  • • Makan atau minum di luar 3x
  • • Tidak memakai atribut lengkap 3x
  • • Tidak melaksanakan tugas 3x / Melanggar tatib ringan 3x
  • • Bertugas tanpa memakai almet 2x
